# Conversão em um clique Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** no Windows, selecionar um livro Kindle já baixado ou um arquivo local e clicar em Converter, sem preencher caminhos de ferramentas.

**Architecture:** um descobridor de livros locais lista arquivos principais nas pastas Kindle; um resolvedor de ferramentas configura o adaptador Windows a partir de pacote relativo ao aplicativo; a GUI roteia pelo diagnóstico de conteúdo e apresenta somente ações de usuário. O núcleo de conversão permanece intacto.

**Tech Stack:** Python 3.12, PySide6, pytest, PyInstaller, Inno Setup, núcleo `kindle_pdf` existente.

**Spec:** [`docs/superpowers/specs/2026-09-26-conversao-um-clique-design.md`](../specs/2026-09-26-conversao-um-clique-design.md).

## Global Constraints

- Não alterar originais nem registrar chaves, tokens ou intermediários em logs e manifesto.
- O Kindle e os livros baixados são pré-requisitos para a rota protegida.
- O produto deve resolver ferramentas de uma pasta relativa à instalação, nunca de um caminho pessoal fixo.
- O primeiro pacote completo é um candidato local; distribuição externa exige licença do arquivador, inventário de licenças e ensaio em Windows limpo.
- O projeto não possui Git: substituir passos de commit por registro de arquivos e resultados no relatório de validação.

## Review Focus

1. Vários pacotes Kindle no perfil: mostrar fontes válidas sem duplicar ou escolher uma conta arbitrária.
2. Pasta `_EBOK` incompleta: não apresentar como livro pronto nem iniciar extração protegida.
3. Arquivador incorreto ou versão Kindle diferente: bloquear a rota protegida com mensagem clara.
4. Arquivo comum sem DRM: não invocar ferramentas protegidas mesmo quando incluídas no pacote.
5. Destino dentro de pasta sincronizada: evitar criar intermediários protegidos nesse destino.
